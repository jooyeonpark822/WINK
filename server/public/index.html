윙맨의 보이스톤과 성격 (시험용)

성격을 고르고 "목소리 들어보기"를 누르면 안경 스피커로 예시 대사가 나와요. "이 목소리로 할게요"를 누르면 이후 대답(음성 대화, 글자 질문, 시나리오별 버튼)에 적용돼요.
성격을 골라 주세요.
지금 적용 중: 불러오는 중...

모터 움직여 보기 (시험용)

안경 보드의 모터를 버튼으로 움직여 봐요. WINK가 답하는 중에도 누르면 움직여요. (답하며 움직이던 동작은 멈추고 눌린 동작을 해요.)

D0, D1 (머리)

올려다보기: 원점에서 팬 오른쪽으로 30도, 틸트 위로 20도. 원점 버튼으로 돌아와요.

D2 (날개)

영점에서 -5도 ↔ +5도로 계속 오가요. 정지를 누르면 영점으로 돌아와 멈춰요.
버튼을 누르면 여기에 결과가 나와요.

시나리오별 버튼 (시험용)

상황마다 WINK의 행동을 바로 실행해 봐요. 말하는 버튼은 소리는 안경 스피커로, 글자는 아래에 나와요. (WINK가 듣거나 답하는 중에는 눌러도 막혀요.)

어색한 침묵

데이팅 도중 대신 플러팅 행동 해주기

눈 화면이 아직 없어서 모터로 대신해요. (윙크 = 고개 갸웃, 하트 = 날개 퍼덕)

눈앞의 사람에게 플러팅하고 싶을 때

안경 카메라가 마지막으로 찍은 사진을 함께 보내서, 옷차림, 표정, 주변을 보고 행동 하나와 멘트 하나를 추천해요. 사람이 안 보이면 방향을 돌려 달라고 해요.
